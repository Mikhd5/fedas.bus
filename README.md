# FEDAS BUS — сайт перевізника

Адаптивний односторінковий сайт FEDAS BUS. Усі вихідні файли розміщені в корені репозиторію, щоб їх було зручно оновлювати з телефона.

## Розгортання у Vercel

- Framework Preset: **Vite**
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

Після кожного оновлення `main.jsx`, `styles.css` або `index.html` GitHub автоматично запускає новий deployment, якщо репозиторій підключений до Vercel.

## Функції

- адаптивна мобільна та десктопна версії;
- інтерактивна схема шести підтверджених країн призначення;
- вибір напрямку з підстановкою у форму;
- інформація про комфорт, безпеку, автопарк і передачу посилок;
- форма підготовки заявки для копіювання та ручного надсилання у Telegram;
- прямі посилання на телефон, Telegram та Instagram.

## Важливо

- Інтерактивна схема показує країни, а не вигадані міста чи зупинки.
- Форма не надсилає бронювання автоматично: вона формує текст, який клієнт самостійно копіює та надсилає у Telegram.
- Розклад, міста, ціни, місткість авто та умови перевезення потрібно підтверджувати у компанії перед публікацією.
