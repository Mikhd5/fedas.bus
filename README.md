# FEDAS BUS — завантаження з телефону

Усі файли цього проєкту навмисно лежать в одному рівні (корені GitHub), без папок `src`, `public` чи `images`. Не створюйте папки під час завантаження.

## Як оновити GitHub з телефону
1. Відкрийте репозиторій `Mikhd5/fedas.bus`.
2. Видаліть старі файли з кореня або замініть файли з такими самими назвами.
3. Завантажте ВСІ файли з цього архіву в корінь репозиторію.
4. Переконайтеся, що поруч із `index.html` видно `styles.css`, `package.json`, `vite.config.js`, усі `.webp`, `fedas-logo.svg`, `fedas-mark.svg`, `robots.txt` і `site.webmanifest`.
5. У Vercel натисніть Redeploy. Framework: Vite; Build Command: `npm run build`; Output Directory: `dist`.

## Важливо
- Сайт зібраний так, щоб вихідний React/JSX був усередині `index.html`; вкладена папка `src` не потрібна.
- React і Babel завантажуються з CDN під час відкриття сторінки.
- Vite збирає CSS, а `vite.config.js` копіює всі локальні зображення та SVG до `dist`.
- Інтерактивна схема показує 6 підтверджених країн призначення, не вигадує міста.
- Форма готує текст заявки для копіювання та ручного надсилання у Telegram; автоматичного надсилання чи бронювання немає.
